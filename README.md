# To-Do App

A clean and beginner-friendly To-Do App built with HTML, CSS, and Vanilla JavaScript.

## Features

- Task Checklist
- Add, edit, and delete tasks
- Mark tasks as completed
- Task statistics
- Clear completed tasks
- Pomodoro Timer
- Calendar
- Current Time
- Light/Dark Mode
- Local Storage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage
- Git & GitHub
- GitHub Pages

## How to Use

1. Enter a task in the input field.
2. Click **Add Task** or press **Enter**.
3. Use the checkbox to mark a task as completed.
4. Click ✏️ to edit a task and 💾 to save the changes.
5. Click 🗑️ to delete a task.
6. Use **Clear Completed** to remove all completed tasks.
7. Use the **Pomodoro Timer** for focused work sessions.
8. Use the **Calendar** to view and select dates.
9. Toggle **Light/Dark Mode** using the button in the header.
10. Tasks and theme preferences are saved using Local Storage.
